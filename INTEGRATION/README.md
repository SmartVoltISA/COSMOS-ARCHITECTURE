# INTEGRATION

This directory connects COSMOS-ARCHITECTURE with prior Ω and SPACE work without destroying repository boundaries.

## Principle

COSMOS is the scientific integration layer. Ω repositories provide methodological and experimental heritage. SPACE repositories provide engineering and architecture context. Each source keeps its own authority and history.

## Rule

`find → audit → classify → link/adapt/import → verify → record`

A source becomes part of COSMOS evidence only after explicit verification and provenance capture.

See [`REPOSITORY_MAP_v0.1.md`](./REPOSITORY_MAP_v0.1.md) for the current audit map.

## Boundaries

- **COSMOS:** astronomical observations, physical models, hypotheses, experiments and results.
- **Ω:** general research methodology, relational experiments and epistemic discipline.
- **SPACE:** AI/system architecture, integrity, protocols, recovery and engineering infrastructure.

The repositories are connected as a graph, not flattened into one repository.
